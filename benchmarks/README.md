# Benchmark network inputs

The benchmark driver is designed for the Hanoi, Net3, and C-Town water distribution networks. Their `.inp` files are not bundled in this repository because the redistribution permissions and attribution requirements for each exact file have not yet been verified.

## Before running a benchmark

1. Obtain each network input from its authoritative source and review the applicable licence or terms.
2. Confirm that your intended use and any redistribution comply with those terms.
3. Place the permitted input files in this directory using the filenames expected by the benchmark driver:
   - `Hanoi.inp`
   - `Net3.inp`
   - `C-Town.inp`
4. Keep the source URL, access date, version, licence/terms, and SHA-256 checksum in your local experiment record.

Do not upload these network files to this repository unless redistribution permission and required attribution have been established. The MIT licence in the repository applies to X-DRL code and documentation, not to third-party network data.

The exact authoritative source and redistribution terms for the specific Hanoi, Net3, and C-Town files used in the historical experiments remain to be documented.
